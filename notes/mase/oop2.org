* Stream Gatherers
** Example on gatherer

     var windows = Stream.of(1, 2, 3, 4, 5)
             .gather(Gatherers.windowSliding(3)).toList();

** Common Gatherers
   - ~fold~: stateful reduction that continues the stream
   - ~mapConcurrent~: concurrent mapping
   - ~scan~: running accumulation
   - ~windowFixed~: non-overlapping batches
   - ~windowSliding~: sliding windows

** Sum

     import java.util.*;
     import java.util.stream.*;

     List<Integer> numbers = List.of(5, 2, 9, 1, 7);

     int sum = numbers.stream()
             .mapToInt(Integer::intValue)
             .sum();

     // same but using reduce
     int sum = numbers.stream()
             .reduce(0, Integer::sum);

* Scoped Values
** Basic Example Of Scoped Values
   #+begin_src java
    import java.lang.ScopedValue;

    public class ScopedValueExample {

        private static final ScopedValue<String> USER = ScopedValue.newInstance();

        public static void main(String[] args) {

            ScopedValue.where(USER, "Alice").run(() -> {
                greet();
            });

            // Outside scope – would throw exception
            // System.out.println(USER.get());
        }

        static void greet() {
            System.out.println("Hello " + USER.get());
        }
    }
   #+end_src
** Nested Scoped Values
   #+begin_src java
    private static final ScopedValue<String> USER = ScopedValue.newInstance();

    public static void main(String[] args) {

        ScopedValue.where(USER, "Alice").run(() -> {

            System.out.println(USER.get()); // Alice

** Scoped Values with Structured Concurrency
   #+begin_src java
     import java.lang.ScopedValue;
     import java.util.concurrent.StructuredTaskScope;

     public class StructuredExample {

         private static final ScopedValue<String> USER = ScopedValue.newInstance();

         public static void main(String[] args) throws Exception {

             ScopedValue.where(USER, "Alice").run(() -> {

                 try (var scope = new StructuredTaskScope.ShutdownOnFailure()) {

                     scope.fork(() -> {
                         return "Task1 sees " + USER.get();
                     });

                     scope.fork(() -> {
                         return "Task2 sees " + USER.get();
                     });

                     scope.join();
                     scope.throwIfFailed();
                 }
             });
         }
     }
   #+end_src

* Flexible Constructor Bodies
** Concept
   - It is now possible to:
     - Have a ~super()~ call after some validation is done on the params passed through the constructor and the same applies to a call to ~this()~
     - Can also log with System.out before a call to super or this
     - *Not allowed*: access to instance attributes (members)
